# Phishing, suspicious email, clicked a link, lost device

Category: security
Owner: Security (L2). The Service Desk does the first 10 minutes. Time: immediate.

1. Gift card, urgent payment, "CEO" asking for a favour: it is phishing. Thank the requester, ask them to report it with the Report Phishing button in Outlook, and delete it. Do not reply to the sender.
2. Clicked a link and typed a password: reset the password now (password-reset.md), require MFA re-registration, sign the user out of all sessions in the admin console, and open a Security ticket with the email headers.
3. Opened an attachment: disconnect the laptop from the network (Wi-Fi off, cable out), keep it on, call Security. Do not power it off.
4. Lost or stolen laptop or phone: wipe it from the device console, reset the password, note the police report number if any.
5. Suspicious sign in alert the user did not start: reset the password, MFA re-registration, Security ticket.

Escalate if: always. Every item here becomes a Security (L2) ticket after the first steps. Many users reporting the same email is an incident (L3).
