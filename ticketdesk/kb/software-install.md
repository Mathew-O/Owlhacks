# Software install and licence requests

Category: software
Owner: Service Desk (L1) for the standard catalogue, L2 for anything else. Time: same day for catalogue apps.

1. Catalogue apps (Chrome, Zoom, 7-Zip, VLC, Adobe Reader): the requester installs from Software Center (Windows) or Self Service (Mac). No ticket needed.
2. Licensed apps (Visio, Project, Acrobat Pro, Adobe CC): need a manager approval on the ticket and a cost centre. L2 assigns the licence, then the app appears in Software Center within an hour.
3. "Licence not valid" on an app that used to work: sign out of the app and back in with the work account. If it still fails, check the licence assignment in the admin console; the licence may have been reclaimed.
4. Anything not in the catalogue: security review first (L2), typically one week.
5. Note the ticket with the licence assigned and close.

Escalate if: the app needs admin rights to run, touches production data, or the licence pool is empty (L2).
